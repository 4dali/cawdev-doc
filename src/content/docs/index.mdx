<CardGrid stagger>
  <Card title="One place, many projects" icon="open-book">
    Every project is a named pointer at a git repository, with its own roadmap,
    changelog and members. One deployment serves a whole team.
  </Card>
  <Card title="Agents get the same verbs you do" icon="puzzle">
    The MCP server hands a coding agent the roadmap and changelog with tokens
    you mint and can revoke — never more than you can do yourself.
  </Card>
  <Card title="Start a session from the console" icon="rocket">
    Point an agent at a roadmap entry, watch it report, answer the question it
    stopped on. Your repositories and your Claude login never leave your machine.
  </Card>
  <Card title="The markdown stays" icon="document">
    <code>ROADMAP.md</code> and <code>CHANGELOG.md</code> are generated exports
    that stay committed and readable. The database is the source of truth.
  </Card>
</CardGrid>

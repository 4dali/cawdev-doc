<CardGrid stagger>
  <Card title="One place, many projects" icon="open-book">
    Every project is a named pointer at a git repository, with its own roadmap,
    changelog and members. Share a project with a <strong>team</strong>, and the
    team plans <strong>sprints across its projects</strong>.
  </Card>
  <Card title="One Roadmap" icon="list-format">
    Roadmap cards and issues share one pipeline, with a lane for what is new and a
    lane for what is planned, each kind keeping its own workflow.
  </Card>
  <Card title="Agents get the same verbs you do" icon="puzzle">
    The MCP server hands a coding agent the roadmap and changelog with tokens
    you mint and can revoke — never more than you can do yourself.
  </Card>
  <Card title="Start a run on a card" icon="rocket">
    Point an agent at a card, watch it report, and answer what is waiting on you
    when it stops to ask. Your repositories and your Claude login never leave
    your machine.
  </Card>
  <Card title="The markdown stays" icon="document">
    <code>ROADMAP.md</code>, <code>ISSUES.md</code> and <code>CHANGELOG.md</code>{' '}
    are generated exports that stay committed and readable. The database is the
    source of truth.
  </Card>
</CardGrid>
